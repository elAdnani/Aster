# Aster design system

Aster should feel calm, warm and trustworthy: a private study rather than a generic SaaS dashboard. The interface uses parchment neutrals, charcoal ink and a restrained terracotta accent. Serif display type gives the assistant a distinct voice; system sans keeps controls crisp and fast.

The chat is the primary surface. Status is always visible, but never alarming. Mobile uses the same information architecture with a dismissible navigation drawer. Motion is limited to short transform/opacity transitions, respects reduced motion, and never delays a response.

Accessibility baseline: semantic controls, visible text labels, 44px touch targets where possible, responsive type, readable contrast, keyboard submission, live chat updates and no hover-only functions.
