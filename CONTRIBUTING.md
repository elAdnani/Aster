# Contributing

Thank you for helping build a private and humane AI workspace.

1. Discuss substantial product or security changes before implementation.
2. Keep the default local, account-free and telemetry-free.
3. Add tests for behavior changes and document security implications.
4. Run `npm.cmd test` and manually verify desktop and narrow mobile layouts.
5. Keep pull requests focused and explain the user outcome first.

Do not add model weights, secrets, generated conversation data or dependencies without a clear reason.
