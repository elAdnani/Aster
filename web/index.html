Organisation de l’installation
  1. 1
    Aster est lancé

    Le service local répond sur cette machine.

  2. 2
    Connectez votre compte, puis choisissez un profil

    La version finale exigera un compte Aster. Chaque compte pourra contenir jusqu’à quatre profils privés avec PIN optionnel.

  3. 3
    Ajoutez un moteur, maintenant ou plus tard

    Installez Ollama depuis sa source officielle puis exécutez :

    ollama pull gemma4:12bEnviron 7,6 Go. Aucun modèle n’est téléchargé automatiquement.
  4. 4
    Gardez l’accès local

    Le mobile, le web distant, Tor et les VPN restent désactivés jusqu’à une configuration authentifiée.
